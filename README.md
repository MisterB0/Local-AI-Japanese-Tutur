# Local-AI-Japanese-Tutur
An open source Japanese tutur using local AI, planned for use on mobile devices with small multimodal models

This app is going to be a mobile app for android and it will use the material 3 expressive design language. The main feature will be local first AI using the same principle as Google AI Edge Gallery to run multimodal models like Gemma4:e2b or e4b. Because of the fully local AI the app will be completely free. The AI will have access to a lot of different tools to make learning easier like generating flashcards, quizzes and audios similar to the functions of googles Gemini notebook. Gamification through streaks and XP will play a role too but can be disabled. The app will be very customizable to suit every users needs.

Currently we are at the start of the project, the AI works for now using ollama and testing using flet for android is in progress.
